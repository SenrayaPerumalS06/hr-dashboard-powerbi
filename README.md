# HR Dashboard - Power BI

## Overview
Employee data analysis dashboard built using Power BI to track HR metrics.

## Tools Used
- Power BI
- DAX

## Key Insights
- Attrition rate
- Attrition rate by department
- Headcount trends
- Education wise attrition
- Attrition Rate by Gender for Different Age Group
